# 畅捷通 T+ 销货单导入

将外部销货单明细导入当前账套，并保留每条源明细的处理结果。

## Language

**销货单**：销售业务单据，由一张表头及其商品明细组成。
_Avoid_：销售出库单（本项目两者不是同一业务对象）

**源用友单号**：原始文件中的外部单据标识，用于识别源端同一张单据。
_Avoid_：SA 编号

**SA 编号**：目标销货单的业务编号，例如 SA2026101200077。
_Avoid_：表头主键、源用友单号

**销售标识**：源文件中识别某条销售明细的标识。
_Avoid_：新明细行号

**档案匹配**：将源客户、商品、人员等业务标识对应到当前账套的档案记录。

**重复跳过**：主表中已存在相同源用友单号，因此整张源单据不再新增。

**导入结果**：每条源明细最终的处理状态及原因，包括成功、跳过或失败等。

**源含税金额**：原始文件每条明细提供的含税金额，本次导入以该值作为金额依据。
_Avoid_：以数量乘单价重新计算的替代金额

**整单失败**：一张源单据的任一明细校验或写入失败，导致该张单据不提交；其他正常单据可继续导入。

**税率档案项**：客户档案引用的税率枚举记录，具有内部标识和税率名称。内部标识不等同于参与金额计算的税率比例。

**计量单位**：销货明细数量采用的存货档案基本单位；原规格型号的末尾汉字不作为本项目单位判断依据。

**普通销售**：业务类型为普通销售的销货单，表达正向销售业务。

**销售退货**：业务类型为销售退货的销货单，表达销售商品的退回业务。编号、数量和金额用于辅助核对业务方向。

**仓库编码**：原始数据用于识别目标仓库的业务编码，与当前账套仓库档案编码匹配。
_Avoid_：以仓库名称或别名自动替代编码

**项目编码**：源文件用于识别销货单所属项目的业务编码，匹配当前账套的项目档案编码。数字外观的编码仍是业务编码。

**数量说明**：将明细数量与其计量单位名称组合形成的可读文本，例如5盒；数量和计量单位仍各自具有独立含义。

**零数量退货**：数量为0的销售退货明细，按正常退货记录保留，不因数量为0而跳过。

**审核信息**：销货单上记录的审核人员、业务日期及状态；这些记录与执行审核业务动作是不同概念。

**含税尾差**：金额按约定精度处理后，无税金额与税额分配产生的差额。

**导入任务**：针对选定账套和已加载源文件，完成校验、重复检查、销货单写入及结果输出的一次处理。

**数据预览**：原始明细加载后、执行导入前的可视化展示；展示成功不代表数据符合导入条件。

**标记数据**：处理过程中获得错误、重复、整单受阻或非阻断说明的源明细，保留原始内容及原因。

**异常结果表**：集中输出未导入明细及需关注说明的结果文件；重复跳过和项目留空分别表明其实际性质。
_Avoid_：将所有标记都解释为写入失败

**目标账套**：本次销货单导入实际写入的业务数据库。
_Avoid_：测试连接使用的默认系统数据库

**结果输出目录**：当前导入文件所在文件夹，用于自动保存本次异常结果表。

**停止导入**：结束当前任务后续处理的操作，保留已经提交的销货单，不表示撤销整次导入。
